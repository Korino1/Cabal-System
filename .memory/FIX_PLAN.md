## КРИТИЧЕСКИЕ

### C-1: Мультиязычные циклы — три разных набора языков

**Проблема:** QA-агент проверяет low-level код (rust-engineer/simd-specialist), где решения могли быть найдены на JA, но QA fallback включает только ZH→EN. QA не может полноценно верифицировать JA-решения.

**Наборы:**
| Контекст | Языки | Где |
|---|---|---|
| Математика/концепт | RU→EN→ZH→DE→FR (5) | mathematician.md, conceptualizer.md |
| Low-level fallback | JA→ZH→EN (3) | rust-engineer, simd, debuger, fixer |
| QA fallback | ZH→EN (2) | qa-agent.md |

**Исправление:** Унифицировать. Low-level fallback остаётся JA→ZH→EN (специфика low-level). QA fallback расширяется до JA→ZH→EN для проверки low-level итераций. Математический цикл RU→EN→ZH→DE→FR остаётся без изменений (другая область).

**Файлы для правки:**
1. `agent/qa-agent.md` — строки 64-70: заменить ZH→EN на JA→ZH→EN
2. `.memory/LOGIC_PROTOCOL.md` — строки 90-100: добавить QA в список low-level fallback

**Файлы для правки:**

## ВЫСОКИЕ

### H-1: ARCH Exit ≠ INTEGRATOR Entry

**Проблема:** ARCH Output: «список недостающих элементов». INTEGRATOR Input: «структура файлов, библиотеки, зависимости». Артефакт ARCH не содержит того, что INTEGRATOR ожидает.

**Исправление:** ARCH Exit Criteria должен явно включать: зафиксированную структуру файлов, список библиотек и зависимостей.

**Файлы для правки:**
1. `.memory/LOGIC_PROTOCOL.md` — строки 293-295 (ARCH Exit Criteria): расширить
2. `agent/architect.md` — строки 78-86: добавить структуру файлов/библиотеки в output

### H-2: global-architect vs architect — дублирование ответственности

**Проблема:** Оба агента отвечают за «структуру файлов» и «зависимости».

**Исправление:** Чётко разделить:
- `global-architect` = декомпозиция задач (Kanban, EP/FEAT/US/T, план работ)
- `architect` = модульная архитектура (контракты, ABI, data layout, структура файлов, библиотеки)

Убрать «структура файлов/библиотеки» из global-architect, оставить только в architect.

**Файлы для правки:**
1. `agent/global-architect.md` — строка 29: убрать «зависимости» из обязанностей, строка 30: убрать «структура файлов»
2. `agent/architect.md` — усилить: явно указать «структура файлов, библиотеки, зависимости — зона architect»
